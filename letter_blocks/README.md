# 单字母印章块（字粒）测试件

用可拆字粒复刻现有整块印章的**字高、字粗、字距**，并标定卡槽底板厚度。

## 为什么测试词选 `AVILOW`

6 个字母覆盖 8 个测试维度，是全表唯一做到的组合：

| 维度 | 字母 | 为什么必须测 |
|---|---|---|
| 极窄块 | `I` | 块宽仅 2.26mm，最容易被卡槽夹裂 |
| 极宽块 | `W` | 块宽 7.68mm，与 I 相差 3.4 倍 |
| 圆形 overshoot | `O` | 墨迹高 6.07mm，比 H 高 0.1mm，暴露基线问题 |
| 平顶基准 | `L` | 墨迹顶正好 5.965mm |
| 负间隙对 | `AV` | 间隙 −0.105mm，字形互相探入对方块区 |
| 最大越界 | `A` | 右腿伸出底板 0.142mm |
| 其他越界 | `V` `W` | 分别越界 0.065 / 0.090mm |
| **不对称字形** | `L` | 唯一能肉眼判断镜像方向对不对的字母 |

`AVIHOW` 曾经是候选，但六个字母全部左右对称，打印出来根本看不出镜像有没有做反 —— 所以用 `L` 换掉了 `H`。

## 方案 3 · 板厚 × 块深 配合矩阵（9 件）

板厚 **1.4 / 1.5 / 1.6** × 块深 **13 / 13.5 / 14**，共 9 件，全部是字母 `H`。

做全组合而不是一次改一个变量：这两个尺寸都可能「差 0.5mm 就松/紧」，
单独试板厚会掩盖块深的问题，反之亦然。9 件一起打，一次比完。

| 板厚 \ 块深 | 13.0 | 13.5 | 14.0 |
|---|---|---|---|
| **1.4** | `H_t1.4_d13` | `H_t1.4_d13.5` | `H_t1.4_d14` |
| **1.5** | `H_t1.5_d13` | `H_t1.5_d13.5` | `H_t1.5_d14` |
| **1.6** | `H_t1.6_d13` | `H_t1.6_d13.5` | `H_t1.6_d14` |

**怎么判断**：每件插进卡槽，记录四项 ——
（1）插入阻力（2）板厚方向旷量（3）块深方向旷量（4）拔出是否费力。

选「插入有轻微阻力、两个方向都不晃、拔出需要一点力」的那一档。
一般板厚按 0.1 的档定，块深按 0.5 的档定。

基线已随块深自适应：13 → 字形中心 6.50，13.5 → 6.75，14 → 7.00，字始终居中。

## 方案 4 · 正式打样（板厚 1.5 / 块深 14）

尺寸定下来后的完整一套：6 个单块 + 1 个整排，词仍用 `AVILOW`。

**为什么还是 AVILOW 而不是真实姓名**：

| 候选词 | 覆盖 | 问题 |
|---|---|---|
| **`AVILOW`** | **8/8** | 唯一全覆盖 |
| `WALKER` | 5/7 | 真实姓名常见，但缺 `I`（极窄）和 `O`（overshoot） |
| `AMANDA` | 2/7 | 打出来「看着挺好」，恰恰掩盖了负间隙、极窄、极宽 |

真实姓名打出来往往「看起来没问题」，问题会等到客户的名字上才暴露。
测试件的目的就是先把自己逼到墙角。

### 尺寸怎么来的

| 项 | 值 | 理由 |
|---|---|---|
| 格内 | **37 × 20mm** | 37 放得下最宽的 `M` 的 5 件（5×6.779+4×0.5 = 35.9）；20 里留 14 给块、6 给刻字 |
| 第 5 列 | **43mm** | 只有 `W` 放不进 37：5×7.681+4×0.5 = **40.4mm** |
| 底板 | 2.0mm | 238mm 跨度要够硬；刻字 0.8 深，还剩 1.2 |
| 壁高 | 9.0mm | 字粒总高 7.5，坐进去比盘沿低 **1.5mm** → 不加盖也掉不出来 |
| 外廓 | **238.0 × 152.4 × 11.0mm** | 2×2 + 5×37 + 43 + 5×1.2 = 238；2×2 + 7×20 + 5×1.2 + 2.4 = 152.4 |

### 刻字

- 字高 **4mm**（`label_size = 6.0 × 4.0 / cap = 4.0235`，和字粒同一套度量）
- 凹深 **0.8mm**，刻在**格底前缘 6mm 空档**里 —— 字粒推到最里侧，字符永远不被挡
- 朝向：站在**正面（-Y）**看是正读的，不用歪头
- 空位不刻字

> 0.8mm 是下限。最初做 0.5mm，实物上几乎看不出阴影；
> OpenSCAD 的预览按**面类型**上色，俯视时凹坑完全不可见，所以另做了
> `build/tmp/zmap.py`：读 STL、只取朝上的面、按 z 值填色（盘沿浅 / 格底中 / 刻字深），
> 用它来验收刻字。以后改刻字深度，先跑一遍 zmap 再打。

### 分件（台面 < 238mm 时）

`tray.scad` 有 `part` 参数：`0` 整件 / `1` 左半 / `2` 右半。
切缝落在**第 3、4 列之间的隔墙里**，两侧各自收口成 2mm 完整外墙，拼起来严丝合缝。

- 拼好后总宽 **240.8mm**（比整件宽 2.8mm，因为一条 1.2mm 隔墙换成了两条 2mm 外墙）
- 两半都是平的，直接摆在一起就能用；要固定就点两点 502 或用胶带
- 台面 ≥ 250mm（如 256×256 的机型）直接用 `tray_full.stl` 更省事

## 方案 7 · 排版长条（底板 + 压盖，6 颗 M3）

```
07_bar/
├── bar_base.stl    155.0 × 26.2 × 5.0mm    12.3 cm³ ≈ 15g   底板
├── bar_cover.stl   155.0 × 30.0 × 9.0mm    41.0 cm³ ≈ 51g   压盖
└── bar_section.png 横截面图
```

**排字区长 145mm**，18 个字符最宽的情况（全 `W`）= 18 × 7.681 = **138.26mm**，
余量 6.7mm。

### 为什么是「上下夹」而不是「侧向螺杆顶紧」

这是这次最关键的一个决定。

`A→A`、`K→A`、`A→V`、`A→X` 这些相邻对的**墨迹间隙是负的**（−0.154 / −0.126 / −0.106），
意思是字粒贴合时，相邻两个字形本身就会互相顶住。整块方案里它们是同一个实体，
没关系；但拆成独立字粒后，侧向大力挤压会把这 0.1~0.15mm 的干涉变成**把 `A` 的右腿压弯**。

上下夹只压 Z 向：字粒被压在「压盖 → 字粒板 → 托唇」之间，横向靠摩擦锁定，
不产生任何侧向挤压力。字距仍然 = 各块 advance 之和，和整块方案逐对一致。

顺带一个推论：**字粒贴合后，遇到负间隙的字母对会自然留 0.10~0.15mm 的缝**，
这是对的，不用去压平它。

### 为什么从上方装字粒

端部装填要一个个塞、塞错顺序还得倒出来；从上方放，摆错一眼看见、随手能改。
代价是没有「顶部挡唇」，靠压盖压住 —— 所以压盖不是可选项。

### 尺寸怎么来的

| 项 | 值 | 理由 |
|---|---|---|
| 排字区 | 145mm | 18 个 `W` = 138.26，留 6.7 余量 |
| 字粒板槽 | 14.1mm 宽 | 字粒板 14.0 + 0.1 配合 |
| **凸出开口** | **7.10mm**（y 3.30~10.40） | 见下，由 `Q` 决定 |
| 托唇 | 前 3.30 / 后 3.70 | 板的两侧各搭 3.3~3.7 |
| 底板厚 | 4.0mm | 下沿离纸面 2.0，压印时托唇不沾墨 |
| 压盖厚 | 9.0mm | 刚度 + 抓握 |
| 压盖宽 | 30.0mm | 比底板宽 3.8，两侧各留 1.9 盖沿（见下） |
| 总高 | **16.5mm** | 字 6.0 + 板 1.5 + 压盖 9.0 |

**开口 7.10 不是随手取的**：普通字母在 Y 向占 y 4.02~9.98，`O/S/C/G` 因 overshoot
到 10.09，而 **`Q` 的尾巴最低到 y = 3.554（比基线低 0.46mm）**。开口若按 3.9 的托唇取
（开口 6.3），`Q` 会被托唇顶住、坐不到底，整排基线就歪了。取 3.30 起点，对 `Q` 留 0.25。

**压盖为什么加宽到 30**：字粒板占掉中间 14.1，两侧只剩 6.0mm，放不下 φ6.2 的沉头孔
（M3 内六角头 φ5.5）。加宽后沉头孔不破边，两侧的 1.9mm 盖沿还正好是抠手的地方。

### 五金

**M3 × 14 自攻螺丝 × 6**，导孔 φ2.7 打在底板上（打穿，拧进去 3.5mm 不会露头）。

- 没有自攻螺丝的话，普通 M3 机丝也能在 PLA 里攻出牙
- 拧到手感略紧就行 —— **压印时手掌往下压的力本身就在夹紧字粒**，
  螺丝主要管「别散架 + 有点基础摩擦」
- 只在有字粒的位置拧紧；空位轻拧，避免压盖被拉弯
- 万一滑牙：滴一点 502，或把导孔扩到 φ4.2 塞 M3 热熔铜螺母

### 用法

1. 字粒按**从左到右的顺序**摆到底板的槽里（这一步顺序就是印出来的顺序，不用倒序）
2. 用手指把整排往一边推紧，让相邻字粒贴合
3. 压盖盖上，6 颗螺丝拧到略紧
4. 压印 → 纸上就是正序

> 注意：字粒贴合是**字距正确的前提**。摆完一定要推紧，别让中间留缝。

### 打印

| 项 | 设置 |
|---|---|
| 摆放 | 底板：平放；压盖：底面朝下（沉头孔在上） |
| 支撑 | **不需要** |
| 层高 | 0.2mm |
| 填充 | 底板 4 墙 / 20%；压盖 4 墙 / 20% |
| 耗材 | 合计约 66g |

## 块的实际尺寸

| 方向 | 尺寸 | 说明 |
|---|---|---|
| **X 块宽** | 2.26 ~ 7.68mm | = 字体 advance，逐字母不同，决定字距 |
| **Y 块深** | **13.0 / 13.5 / 14.0mm** | 卡槽夹持要求；字始终居中，上下各留 3.52~4.02mm |
| **Z 总高** | 板厚 + 6.0mm | 板厚 1.0~1.5，所以总高 7.0~7.5mm |

> **Y 向为什么是 13mm**：初版按整块方案的底座宽 6.6mm 做，实测卡槽夹不住 ——
> 卡槽需要 13mm 才够。改 Y 不影响字距（字距只由 X 向 advance 决定），只是块变深。
>
> 如果 13mm 是卡槽**内腔**尺寸，实际块应做成 12.9 左右留配合间隙；
> 如果 13mm 是块的外廓目标值，当前就是对的。先按 13.0 打一个试。
>
> 13mm 深的块压印时只有中间 6mm 的字接触纸面，两侧各 3.5mm 悬空。
> 靠卡槽整体夹紧来保证受力均匀，**不要用手指直接捏块压印**。

## 拼装顺序：必须从右往左

这是整个方案最容易踩的坑，务必先看这一段。

印章压印时整排要翻转 180°，**字母顺序会跟着反转**。所以：

- 要印 `AVILOW`，从左到右要摆成 `W O L I V A`
- 也就是说，**先放最后一个字母，最后放第一个**

`out/02_spacing/AVILOW_strip_t1.2.stl` 已经按这个规则倒序排好了，
所以它掰开后的块序就是正确的，照着摆不会错。

> 为什么不干脆让块上的字正着写、正着摆？因为印章必须镜像才能印出正字，
> 而镜像一旦做在单块上，顺序就必然反转。除非改成「上下镜像」，
> 那样顺序不变，但块上的字母会上下颠倒（`V` 变成 `Λ`、`W` 变成 `M`），
> 拼装时更难认。两害相权，选了「字形可读、顺序倒着摆」。
>
> 正式版建议在每块底板侧面刻一个正字标识，拼装时按标识找块，就不会摆错。

## 方案 1 · 底板厚度标定（7 件）

同一个字母 `H`，底板厚度 1.0 / 1.1 / 1.2 / 1.3 / 1.4 / 1.5 / 1.6mm。

用 H 而不是别的字母，是因为它**没有 overshoot、没有越界、左右对称**，任何异常都只能来自板厚本身。

> **已重新生成**：块深从 6.6mm 改为 13.0mm，之前打的那批 H 尺寸不对，需要重打。
> 建议先只打 `H_t1.2.stl` 一个，确认能插进卡槽、13mm 方向松紧合适，再补其余六个厚度。

**怎么判断**：把 7 件依次插进卡槽，记录（1）插入阻力（2）横向旷量（3）拔出是否费劲。
推荐取「能顺利插入、横向无明显旷量」的最大值，再减去 0.1 作为槽宽。

> 1.0mm 在 0.4 喷嘴 / 0.2 层高下只有 5 层，偏软；实测若 1.0 已经变形，最小可用值大概率在 1.2 附近。

## 方案 2 · 字距复刻（6 件 + 1 整排）

每个字母一块，块宽 = 字体 advance，底板 1.2mm。

**单块拼装后，总宽应为 31.65mm**（= Σadvance），这是最直接的验收数字。

整排件 `AVILOW_strip_t1.2.stl` 已按正确字距排好（块间留 0.5mm 便于分离）。
两种用法都行：
- 不掰开，直接压印 —— 就是一枚字距正确的印章，拿去和整块方案对比
- 掰开，6 块按**原顺序**贴合重拼（掰开时记住左右顺序，是 `W O L I V A`，不要按字母表重排）

**对照组**：用现有 stampgen 生成一枚 `AVILOW` 整块印章，
参数为字号 6 / 间距 1.0 / 底座宽 6.6 / 底座高 10 / 字高 6 / 留白 3.5，
程序会给出底座长 **38.76mm**。把两枚印章叠在一起看间隙是否一致。

## 四个关键设计决策

### 1. 块宽 = advance，不是「统一宽度」

Arial 的 advance 从 2.26mm（I）到 7.68mm（W）。只有块宽严格等于 advance，
拼装后每一对相邻字母的墨迹间隙才与整块方案**逐对相同**。

改成统一块宽，字距会立刻失控：`I` 和 `W` 的墨迹宽差 6.9mm，同一块宽下间隙差可达 3mm。

### 2. 统一基线，不按各自包围盒居中

`O` 的墨迹是 −0.10 ~ +6.07（上下都溢出），`L` 是 0 ~ 5.965。
如果每个块按自己的墨迹居中，`O` 会比 `L` 低 0.05mm，拼起来高低不齐。

模板里所有字母共用一条基线：`baseline_y = 块深/2 − cap高/2 = 0.318mm`。

### 3. 只镜像字形，不镜像块

如果把整个块镜像，字母在块内的左右留白会互换，块宽 = advance 时字距就错位了。

正确做法（模板已实现）：字形绕 x=0 翻转后，再平移 `(ink_xmin + ink_xmax)`，
使其墨迹仍落在 `[ink_xmin, ink_xmax]`。字形是反的（印章需要），但占位与整块方案完全相同。

### 4. 整排件倒序存放

`render_strip` 在传参时把字母序列 `[::-1]` 倒过来，块内字形仍然是镜像的。
所以 STL 从左到右读是 `W O L I V A`（且每个字母是反的），压印翻转后纸上才是
`A V I L O W` 正读。

预览图 `AVILOW_imprint.png` 是**再镜像一次**得到的「压印效果」，看到的是正序正字 ——
它和 STL 长得不一样，这是正常的。

## 已知的越界情况

7 个字母的墨迹会伸出自己的底板，这是 Arial 字形的固有设计，不是 bug：

| 字母 | 越界量 | 原因 |
|---|---|---|
| `A` | +0.142 | 右腿在基线处最宽，超出 advance 格子 |
| `K` | +0.114 | 右下斜笔 |
| `W` | +0.090 | 四个斜笔的总宽超过 advance |
| `X` `Y` `V` | +0.065~0.077 | 斜笔两端 |
| `R` | +0.035 | 右下腿 |

这些字母与邻块靠「高度错开」才不碰撞（A 的右腿在基线，V 的左臂在大写字高），
打印上可行，但底板边缘会有 0.14mm 的悬挑。**这正是本次要重点观察的地方。**

## 打印参数建议

| 项 | 值 | 理由 |
|---|---|---|
| 喷嘴 | 0.4mm | 笔画 0.79mm，0.4 喷嘴刚好两线 |
| 层高 | 0.2mm | 1.0mm 板 = 5 层，能打但偏软 |
| 墙 | 3 层 | 底板薄，靠墙保证强度 |
| 支撑 | 不需要 | 字形竖直挤出，仅 A/V/W 有 0.14mm 悬挑 |
| 速度 | 30mm/s 以内 | 笔画高宽比 7.5:1，太快会晃 |
| 摆放 | 底板贴平台 | 字朝上，印面平整 |

## 验收清单

1. **总宽**：6 块贴合后 31.65mm（卡尺，允许 ±0.1）
2. **块深**：每块 Y 向 13.0mm，字上下居中（上下各 3.52mm）
3. **间隙**：`A→V` 几乎接触（−0.105mm），`I→L` 明显最宽（1.36mm）
4. **顺序**：从左到右摆 `W O L I V A`，压印后纸上是 `A V I L O W`
5. **镜像**：`L` 压印后竖笔在**左**、底横在**右**（STL 里是反的才对）
6. **基线**：6 个字母底边用直尺靠，应完全齐平
7. **越界**：`A` 右腿、`W` 两端看有没有毛边或塌陷


字体、字号、块深、字高都在 `scripts/build.py` 顶部常量里改，改完重跑即可。
收纳盘的格数/格宽/格深/壁厚/刻字深度在 `scad/tray.scad` 顶部，`build.py` 里
`TRAY_COLS`、`TRAY_WIDE_COL` 要和它保持一致（决定每格刻什么字符）。

长条的长度在 `scad/bar.scad` 顶部的 `chan_len`（排字区）和 `base_len`（总长，
= chan_len + 2 × bridge）。做短一点的（比如 10 个字符）就改这两个值，
压盖跟着 `base_len` 变；螺丝位置 `screw_x` 要跟着重排，别落在挡墙上。
