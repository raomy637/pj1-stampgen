# 2026-10-31

## 印章 STL 按高度归档

- 新增 `tools/stl_bbox.py`：解析二进制/ASCII STL，输出包围盒 X/Y/Z 与三角面数（`python tools/stl_bbox.py <目录>`）。
- 新增 `tools/organize_by_height.py`：按 Z 轴高度分组，容差 `--tol`（默认 0.01mm）判同高，支持 `--dry-run`；文件夹命名 `高度{值:.3f}mm`。
- 对 `letter_blocks/out/印章` 执行：16 个 STL → 9 个高度分组（4.771 / 11.000 / 12.000 / 17.000 / 19.615 / 19.942 / 20.800(7个) / 20.904 / 22.000）。
- 注意：`猫爪1.stl` 的 zmin=2.000，模型悬空 2mm 未贴打印平台，高度按 Z 跨度计为 22.000。
- 约定：模型"高度"取 Z 轴跨度（打印高度），非最大外形尺寸。
